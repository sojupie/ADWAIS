Calendar Responsiveness & Refactoring Options

Select the design directions you prefer for the responsive calendar, database models, and settings views.

A

Responsive Calendar & Layout (Month / Week / Schedule Views)

Show color-coded circles instead of text on mobile month-views. Add a view selector for Month / Week / Schedule (which displays a list of up to 20 events). Add mobile responsiveness and minimum heights to OfficeContext.tsx, and restore the "+ Add Event" button visibility.

B

Strongly-typed Enums (EventType & Recurrence)

Refactor C# OfficeEvent model properties EventType and Recurrence to use existing domain enums (EventType and RecurrenceType) using EF Core .HasConversion<string>(). This keeps the database columns fully compatible and stores enum values as strings without requiring complex database migrations.

C

Emoji Representation & Event Rendering

Associate each EventType with a specific emoji (e.g. 🤝 for Meeting, ☕ for Fika, 🚀 for GoLive). Render these emojis next to events in both the main Calendar views and the OfficeContext schedule list.

D

Integrated Calendar Subscriptions Page

Remove subscription settings from the Calendar modal popup. Build a dedicated management panel directly inside the /settings/configuration settings page, enabling admins to view, sync, add, or delete subscriptions alongside system-wide settings.

E

Real Weather Polling Widget

Integrate a real public weather source (Open-Meteo API, no key required) in the backend or frontend. Add WeatherLocationName, WeatherLatitude, and WeatherLongitude settings to the GlobalConfig model so admins can adjust their location in settings, updating the OfficeContext widget dynamically.
